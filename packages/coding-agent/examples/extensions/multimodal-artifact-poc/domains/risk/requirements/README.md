# Risk Domain Pack — Requirement Planning

领域包只携带业务词汇与安全默认值，**不包含** SQL、具体表名、工具名、
固定数据集 ID、用户权限或自动批准策略。

## 适用场景

- 个人贷款 / 企业贷款 / 信用卡组合分析
- 申请量、通过率、放款额、逾期率、坏账率等风险指标
- 模型质量指标 AUC / KS / PSI
- 与前周期对比、归因分析

## 使用规则

1. 只有用户请求语义**明确**属于风险领域（关键词命中）时才启用本包。
2. `domainHint=risk` 只是提示：语义不匹配时不得强制采用风险指标。
3. 领域默认值（如时间范围「最近 30 天」）写入 `assumptions`，
   标记 `source=DOMAIN_DEFAULT`，必须对用户可见。
4. 高风险假设（影响 MEDIUM/HIGH）需要用户确认，不得静默采用。
5. 关闭 `round4.domain_pack` 后只能使用 generic 包：不自动补充
   风险指标，并产生更多通用澄清问题。

## 风险指标定义（示例）

| 指标 | 定义 |
|------|------|
| 申请量 | 周期内贷款申请笔数 |
| 通过率 | 审批通过 / 申请总量 |
| 放款额 | 实际放款总金额 |
| 逾期率 | 逾期余额 / 应还余额 |
| 坏账率 | 核销金额 / 放款金额 |
| AUC | 模型 ROC 曲线下面积 |
| KS | 评分分布 Kolmogorov-Smirnov 统计量 |
| PSI | 评分分布稳定性指数 |
